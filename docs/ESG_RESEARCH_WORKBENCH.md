# 制造业场所历史湿热环境研究工作台

2026-11-05后续：v0.3新增首批五场所阶段1—3研究报告，详见[结果与复现](ESG_FIVE_SITE_RESULTS.md)。下文保留v0.2研究数据包的方法与范围；新增案例只使用首批五场所的两个有效主格、50个网格年，不能与全目录的4格/100个网格年混淆。

界面版本：v0.2；修订日期：2026-11-05。公开场所证据快照保持 2026-10-29。本工作台把现有公开制造业试点组织为可检查样本、空间匹配、年度完整性、逐日数据和原始证据的研究界面。入口为 [本地页面](../apps/factory-pilot/dist/index.html)，操作与完整复现命令见 [README](../apps/factory-pilot/README.md)。

## 研究对象与分析单元

研究问题是：公开资料定位的制造业场所，在其当前映射位置所对应的 ERA5 网格中，2000—2024 年夏季具有怎样的历史湿热环境？场所是身份、地址和地图边界的关联对象；气候数据单元是不同 `grid_id`，而非企业数量。

| 层级 | 当前数量 | 使用口径 |
| --- | ---: | --- |
| 场所目录 | 35 | 5 个公开资料已核验、30 个待核验候选 |
| 不同主匹配网格 | 5 | 4 个陆地有效格、1 个未通过陆地掩膜的格 |
| 主结果有效场所 | 34 | 同格场所共享全部气候序列 |
| 不同有效主网格 | 4 | 主分析去重单元；不表示统计独立 |
| 不同主网格—年份组合 | 100 | 4 格 × 25 个夏季 |
| 场所年度展开记录 | 850 | 34 处 × 25 年，包含共同网格重复 |
| 仅用于敏感性的附加网格 | 1 | 不纳入有效主网格及主年度样本数 |

仅筛选首批 5 个已核验场所时，4 个有效场所对应 2 个有效主网格；特斯拉主匹配未通过陆地掩膜。全样本中的共同主格关联数量为 3、22、6、3，不能直接对 34 个场所的数值求平均并把它解释为等权网格平均或地区平均。不同网格之间也可能存在空间相关性。

界面将网格表和场所关联表分开；年度比较每个有效主格只画一条曲线，统一纵轴 0—92 天。筛选改变当前展示的场所关联与主网格集合，不改变原始结果或核验状态。

## 气候变量、年度完整性与逐日数据

输入是既有 `humid_heat_jja_2000_2024_bjt.nc` 的 `daily_max_heat_index_c`，配合 `heat_risk_categories_jja_2000_2024_bjt.nc` 的 `land_mask`。网格分辨率为 0.25°；日界为 UTC+8，时间范围为 2000-06-01 至 2024-08-31 内的各年 JJA，并非连续保留全年。日最高 HI 是处理后的热指数，不是气温、小时原值或厂区实测值。原变量说明为按北京时间逐日取小时 NOAA/Rothfusz HI 的最大值；任一小时缺失时该日为 NaN。工作台读取现成日值，不重新计算小时过程。

每个夏季预期 92 天。只有日期齐全且每日值有限时，`complete_summer` 才为真。年度表同时显示 `expected_days`、`valid_days`、`missing_date_days`（时间轴缺少的日期）和 `nonfinite_days`（已有日期上的 NaN/无穷值），避免把缺日期与已有记录中的缺测混在一起。不完整夏季仍保留年度记录，其阈值天数和最长连续天数为空，且不纳入汇总。当前四个有效主格均有 25 个完整夏季。

| 指标 | 定义 |
| --- | --- |
| 年阈值天数 `days_ge_threshold` | 当年 JJA 日最高 HI ≥40.6°C 的天数 |
| 年最长连续天数 `max_consecutive_days` | 当年 JJA 连续达到上述阈值的最长天数，每个夏季重新计数 |
| 平均阈值天数 | 对完整夏季的年阈值天数取平均；单位为天/夏季 |
| 汇总最长连续天数 | 所有完整夏季的年最长连续天数中的最大值，不是平均值 |

年度变化图不包含趋势拟合、显著性检验或归因。逐日图只展示选中的一个夏季，带有 40.6°C 阈值线，不跨冬季连接。表格显示两位小数，阈值判断使用未舍入原值；研究逐日 CSV 序列化解码后的原数值，非有限值为空，不填零。时间轴完全缺少的日期由年度完整性列报告，不凭空产生有效日值。

## 厂区边界、代表点与敏感性

空间图使用 [factory_boundaries.geojson](../data/site_inputs/factory_boundaries.geojson) 存档的真实 OSM 对象多边形坐标，同时绘制代表点和附近最近中心分区；这里的“真实多边形”指原地图对象几何，不表示地籍测量或现场确认。坐标为 WGS84。通常采用已检查位于多边形内的包围盒中心；长安福特杭州工厂的包围盒中心在凹多边形外，因此采用中纬线最长内部区段中点。代表点不是工作位置、测量中心或面积加权质心。

主匹配沿原气候文件的经纬度轴分别取最近中心，等距时按原文件顺序。代表点到网格中心的大圆距离仅描述匹配距离，不能解释为坐标误差或置信区间。源文件陆地掩膜规则为 ERA5 陆地比例 ≥0.5 记为 1，否则记为 0；筛查只接受 `land_mask == 1`。未通过掩膜表示该粗网格不进入本次陆地筛查，不表示真实厂区在海上。

研究构建器对厂区包围盒计算可能涉及的最近中心分区，连边界接触也作为保守候选。包围盒候选不等于真实多边形已经覆盖这些分区，也不是位置概率分布或统计置信区间。敏感性视图列出候选格结果；主匹配和有效候选都存在数值时才计算均值差，不用候选格替换主格。

| 特斯拉上海工厂情景 | 网格（纬度，经度） | 状态 | 平均阈值天数 | 汇总最长连续天数 |
| --- | --- | --- | ---: | ---: |
| 原代表点主匹配 | 30.7500,121.7500 | `non_land_grid`，掩膜为 0 | 空 | 空 |
| 包围盒附加候选 | 31.0000,121.7500 | 陆地、25 个完整夏季；`sensitivity_only` | 10.52 天/夏季 | 14 天 |

10.52/14 仅用于展示位置选择可能带来的差异。特斯拉的主结果仍为空，没有相对主结果的数值差，也不因候选存在而变成第 35 个有效场所或第 5 个有效主网格。海洋掩膜剔除、气候数据不完整、坐标无效以及场所身份待核验是不同状态；身份核验通过不保证主气候结果有效。

## 日期与原始元数据

| 时间字段 | 意义 |
| --- | --- |
| 气候时期 | 2000—2024 年 JJA 的历史环境资料 |
| 证据原文日期 | 车型公示、政府公告、产品生产日期、证书日期等；在各场所 `evidence_date_note` 中说明 |
| OSM 版本时间 | 地图对象 `osm_timestamp`，不是建厂或现场核验日期 |
| 证据获取时间 | 每项来源的 `retrieved_at_utc`，不是原文发布日期 |
| 公开证据快照 | 2026-10-29，即目录 `reviewed_on` |
| 研究包生成时间 | `generated_at_utc`，重新构建会更新 |
| 界面修订日期 | 2026-11-05，不更新场所证据 |

已有场所证据不能证明厂区在整个 2000—2024 年间存在或持续生产。证书用于公开生产地址与范围佐证，未据此作实时认证有效性判断。

研究包完整保留源文件的全局属性、HI 变量属性、掩膜属性。HI 派生变量的 `units=Celsius`、`long_name=daily maximum heat index` 和 `description` 与来源 `src/process_humid_heat.py` 的处理含义一致，但同一变量仍继承 `GRIB_units=K`、`GRIB_name=2 metre temperature`、`GRIB_cfVarName=t2m` 等原始温度元数据。这是源文件属性冲突，工作台在方法与证据视图及 `research_manifest.json` 明示。采用派生变量的摄氏热指数定义；保留冲突属性以供审查，不改写源 NetCDF，不额外进行 273.15 换算。

## 数据包、复现与核对范围

[esg_build_research_data.py](../tools/esg_build_research_data.py) 的六个必需参数为 `--catalog`、`--boundaries`、`--screening`、`--heat-index`、`--risk`、`--output`。沿用 README 的本机变量后，可单独重建研究包：

```powershell
& $pilotPython -m tools.esg_build_research_data --catalog data/site_inputs/factory_sites.json --boundaries data/site_inputs/factory_boundaries.geojson --screening $pilotScreening --heat-index "$pilotClimate\humid_heat_jja_2000_2024_bjt.nc" --risk "$pilotClimate\heat_risk_categories_jja_2000_2024_bjt.nc" --output apps/factory-pilot/dist
```

构建器先核对既有筛查清单中的气候与输出哈希、场所 ID、边界 ID、坐标、主格以及气候/掩膜坐标轴一致性，再从所需网格读取数据。原 850 条场所年度记录的完整性、阈值和年度数值逐项比较；另用连续真假序列分组检查完整夏季的阈值天数与最长连续天数。输入哈希在打包前后再次核对。这些是可复现性和一致性核对，不构成对 ERA5、热指数模型或厂区实况的独立验证。

| 研究产物（`apps/factory-pilot/dist/` 下） | 内容和使用方式 |
| --- | --- |
| `research-data.js` | 浏览器离线数据：不同网格的日/年序列、场所关联、边界、策略和元数据 |
| `downloads/research_grid_summary.csv` | 6 个不同候选网格，包括未通过掩膜的主格及 `sensitivity_only` 附加格；可按 `analysis_role` 区分 |
| `downloads/research_grid_annual.csv` | 所有有效候选格的年度记录，共 125 行；其中 100 行为有效主格，25 行仅用于敏感性；含 `analysis_role` |
| `downloads/research_grid_daily.csv` | 所有有效候选格的 JJA 逐日值，包含敏感性附加格；含 `analysis_role` |
| `downloads/research_site_grid_links.csv` | 各场所的 `primary_grid_id` 和保守 `bbox_grid_ids` |
| `downloads/research_manifest.json` | 输入/输出 SHA-256、时期、策略、原始属性和构建核对记录 |

年度、逐日和汇总 CSV 均可通过 `analysis_role == primary` 筛选主分析记录；`sensitivity_only` 记录仅用于附加情景。不能将研究年度文件的全部 125 行直接称为 100 个主格—年份样本。需要场所关联时，再按 `grid_id` 连接网格汇总表或场所—网格对应表。原 `site_summary.csv`、`site_annual.csv`、`screening_manifest.json` 和 `factory_sites.json` 继续保留，场所年度文件保留其展开语义。

[esg_build_dashboard.py](../tools/esg_build_dashboard.py) 只覆盖基线包及其清单，不覆盖研究文件或界面源码；基线更改后应顺序运行基线和研究两个打包器，保持来源一致。原 `package_manifest.json` 只验证基线数据，研究产物使用单独的 `research_manifest.json`。测试与浏览器检查命令见 README；检查记录和证据核验应分别解读。

2026-11-05 自审通过 24 项 Python 测试和 14 项浏览器检查，汇总见 [研究工作台检查记录](validation/ESG_RESEARCH_WORKBENCH_20261105.json)。本机浏览器记录与截图位于 `<LOCAL_EVIDENCE_ROOT>\esg-research-workbench-20261105\ui_qa`。

## 适用范围

当前样本由公开证据与可获取地图对象构成，以上海闵行为主，另含杭州和太仓地点，不是长三角制造业的概率样本。30 个候选仍需生产地址与企业实体交叉核验；地图工业标签不能替代核验。边界和代表点也未验证厂内工作环境。

0.25° 再分析网格不能解析厂区建筑、室内热源、辐射、通风或作业安排。员工人数、班次和防暑措施缺少场所级证据，继续为空。现有结果适用于公开资料方法试点与后续证据核查，不据此计算职业合规结论、人员热暴露、企业风险评级或地区制造业风险比例。

原始公开材料仅存于本地证据目录，保留原权利；OSM 派生数据的署名与许可见 [第三方数据说明](../data/site_inputs/THIRD_PARTY_DATA.md)。本项目的资料核验、数据交叉核对和界面检查均属于作者自审。
