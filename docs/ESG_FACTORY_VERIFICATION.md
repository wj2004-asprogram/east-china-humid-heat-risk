## 坐标与采样方法

坐标来自 OSM 原始 XML 中的闭合 way 节点。OSM 明确使用 [WGS84](https://wiki.openstreetmap.org/wiki/Converting_to_WGS84)；没有将高德、百度或未说明 CRS 的环评坐标直接用于气候计算。环评地理位置仅作为格力厂区的空间佐证。

通常取厂区包围盒中点，并验证其处于边界内；福特厂区为凹形，包围盒中心落在边界外，取厂区中纬线最长内部区段的中点。两种方法分别记录在 `coordinate_method`，均非测量中心或工人位置。保留原始边界、OSM 对象编号、版本、更新时间、获取时间及哈希。主站 API 不提供 Overpass 的全局数据库时间，因此没有将对象更新时间冒充全库时间。

首批完成后，保存 `first_five_screening/verification_gate.json` 及全部输入快照，再获取两个小范围地图响应：

- 闵行：`bbox=121.34,31.01,121.41,31.09`，选取27个候选；与首批采埃孚对象去重。
- 太仓：`bbox=121.08,31.43,121.16,31.50`，选取3个候选。

候选仅根据明确的制造业相关名称及 `industrial/works` 标签选取，生产地址、法人、行业均保持待核验；不按品牌名分配总部信息。35个代表点全部在相应地图多边形内，23组包围盒相交进一步按多边形检查，没有检测到内部重叠。不同 OSM 对象仍可能有同一厂区分拆或地图错误，剩余30个需进一步确认。

未计入的对象包括：闵行经济开发区和莘庄工业区整体、创意园、均胜上海总部、燃气储配中心、电厂、仅有宽泛机构名称的用地，以及存在旧址/名称歧义的地点。太仓旧“舍弗勒一厂”未计入，优先保留为重新核查地址的线索。未把检索返回的学校、商店、充电站当成工厂。

该采样高度集中于上海闵行，江苏仅太仓3个候选，尚无安徽样本。无法据此推断长三角制造业分布、行业热暴露排名或地区总体风险。
