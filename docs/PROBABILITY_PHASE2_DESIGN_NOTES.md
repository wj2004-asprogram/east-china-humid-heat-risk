# 第二阶段：特征与真实基线执行说明

日期：2026-11-05。依据：[实验协议](PROBABILITY_EXPERIMENT_PROTOCOL.md)及[配置](../configs/probability_protocol_v1.json)。本文件落实本轮已授权的完整特征与四类真实基线，不改变最终测试年份、特征组或空间划分。结果出来后只做一次针对泄漏、比较公平性和解释边界的实质审查。

## 本轮实施范围

- 2000—2014年：拟合季节概率、条件转移、正则逻辑回归，以及相应标准化参数。
- 2015—2017年：固定候选选择与逐年、新发生风险集评价。
- 2018—2019年：仅准备特征；不拟合概率校准、不搜索告警阈值、不报告模型性能。
- 2020—2024年：不解码气象值或标签，不预测、不评价。本轮不需要先生成这些年份的完整特征。

普通时间实验使用全域合格查询格；严格空间实验拟合及本轮验证均只用T中的1,299个合格查询格。严格邻域来源保持固定的1,302个T格，H与缓冲带不进入来源或监督统计。H的最终空间评价仍留到2020—2024年正式测试。因此，本轮strict结果检验的是空间排除条件下T区域的跨年表现，不能称为已证明向H迁移。

## LR选择规则

对普通实验与strict实验分别执行一次以下过程：

1. 使用该范围的F4、lag=1完整共同训练样本；标准化只fit 2000—2014年。
2. 仅拟合预设四个C：0.01、0.1、1、10；L2、无类别重加权、无过采样、最大迭代2000。锁定实际求解器与版本，未收敛如实记录。
3. 在2015、2016、2017年分别计算原始概率BS，再将三年等权平均；以均值最低选C，同分取较小C。
4. 本范围其余已执行特征臂与lag=2复用该C，各自重新只用2000—2014拟合模型及对应标准化参数。**F0不得独立选择C**，也不得把全域选定的C直接用于strict而省略严格范围的独立选择。

选定C后，不并入验证年重拟合。F4是使用完整信息的强LR基线；F0是纯温度对照，后续F1−F0比较才回答新增近期水汽信息的价值。F4优于F0不能单独归因为湿度，因为它同时增加夜间、区域和历史HI信息。

## 特征与共同样本的必要细节

注册表每个日变量包含3个滞后值及3/7日窗口的mean/min/max，共9列。预期组维数为C=6、T=27、M=54、NT=3、NM=2、RT=4、RM=8、H=13，因此F0=33、F1=87、F4=117列。若工程存储另有元数据列，不能把它们计入或自动喂给模型。

夜间按结束日期A归属，取A−1日20时至A日08时之前的12个整点。温差为T(20)−T(07)，相隔11小时，12个点全部有效才有效。夜间特征只要求所用A夜间完整；不要把6月1日不完整夜间错误传播为整个7日历史不完整。最早共同目标6月9日分别需要6月8/7日结束的夜间，而6月1日仅用于完整日统计历史。

共同资格以所有计划特征和两种lag的实际依赖并集构造；普通与strict各有自己的共同索引。三类经验基线和LR在同一范围、同一目标键上评价，不为简单基线保留额外日期、不为某LR删除较难样本。D−2输入状态只能是y(D−2)及以前，评价表里的y(D−1)不得进入特征、转移条件或模型路由。

事件标签按未四舍五入的HI≥40.6°C计算；若特征采用压缩浮点存储，应先按标签源精度得到布尔标签，再转换特征dtype，避免40.6附近的数值转换改变标签。缺值继续为缺失，不当作无事件。

## 本轮结果的报告与解释

各年及三年等权汇总至少报告共同样本数、发生率、BS、相对固定基线的BS差、AP；PR梯形面积若列出，必须与AP分开命名。新发生风险集为y(D−1)=0，包含0→0和0→1，不能只在新发生阳性上计算识别能力。D−2的这一分组是事后诊断。

未拟合校准器时，本轮只报告raw概率；固定0.5告警可用于研究诊断并列TP/FP/FN/TN，不能标成已校准规则。10%校准期告警预算留待校准阶段。持续性在lag=1新发生风险集中恒为0，其召回为0是定义导致的预期结果，不作为新增信息成功的充分证据。

2015—2017同时承担选C和本轮评价，因此结果是**验证期证据**，包含有限模型选择带来的乐观性；不能声称已完成独立测试、跨区域迁移证明或实时预警验证。本轮三年逐年差值直接展示，不把三年相关样本包装成精确显著性结论。最终测试与正式不确定性分析仍按原协议在后续冻结后完成。

## 实质审查记录（完成）

审查对象为 [run1](../data/probability_phase2/experiments/run1/design_lock.json)、完整特征构造、三类经验基线、LR执行器、评分函数及[最终阶段报告](PROBABILITY_PHASE2_RESULTS.md)。结论：**当前实现与保存产物支持下述有限的验证期结论，未发现需要重跑的时间泄漏、空间越界、选参偏离或比较样本不一致问题**。本次审查在长时间拟合期间开始，完整产物落盘后接续结审，未另起重复审查或重新训练。

已核对的实质边界：

- runner的读入年份硬限制为2000—2017；拟合矩阵与StandardScaler仅2000—2014，验证为2015—2017。F4、lag1按四候选C选参，其他臂和lag2复用本范围C，strict另作同一有限选择。2018—2019未进模型runner，最终测试年不在允许范围。
- 特征构造使用真实日历索引，D−2的最新日、7日窗口、夜间及事件状态均前移；标签先于X存储转换计算。strict查询只为T，区域来源使用固定成员且缺值不重新归一化。新发生评分同时包含0→0与0→1。
- 对2015年已保存数组独立核查：普通132,720行、strict 109,116行且全部为1,299个T查询格；两lag均117列且有限，样本键唯一。特征组维数与注册表一致，y_anchor与各自状态列一致，previous_y与lag1状态一致。
- 在2015年四个代表性格日核对日统计锚点、7日均温、夜间降温和标签，时间对齐正确。均温按正序与实现倒序求和相差最多3.8147×10⁻⁶°C，属float32求和顺序舍入；核对采用10⁻⁵°C绝对容差。
- 对2015年普通实验两lag的持续性、格点季节概率、区域季节概率、条件转移共8组预测，独立核对全部行键及标签一致；对全样本和新发生风险集重算BS，并以scikit-learn的average_precision_score核对AP，与CSV差值均小于10⁻¹⁴。

发现并已通知工程落实的唯一说明性修正：日T/Td/RH/HI数组实际为float32、夜间数组为float64，旧注释“保留float64”不准确。现改为保留计算dtype，事件标签独立于X转换；不更改既有数值或重训。阈值附近标签与特征存储精度的区分已有专门合成检查。

已完成的普通实验经验基线三年等权BS如下，仍属验证期证据：

全样本共同验证行数398,160，新发生风险集298,895行。D−1持续性在新发生集恒预测0，三年等权BS与AP均为0.0854，符合定义；这一现象不能单独证明湿度有预测增量。

最终LR核对结果：两个范围均选择C=0.1。8次搜索拟合中6次收敛；strict的C=1和10达到2000次上限未收敛，按预设规则排除，没有追加迭代、更换求解器或补充候选。加上固定C复用，本轮共18次拟合、16次收敛，导出12个收敛LR模型。失败的两个候选未进入预测文件。

对全部12个导出模型核对训练年份、训练行数、C、特征名单与收敛状态；对其36组验证年度预测核对行键和标签，并重算全样本、新发生、持续/解除三类风险集的108个BS，均与CSV相符（绝对差小于10⁻¹⁴）。用保存的scaler、系数和截距重建各模型2015年的三个代表性样本概率，最大差5.7246×10⁻¹⁷。12个湿度对照的逐年差值和汇总与原指标一致。已检查报告图的符号、年份、空间范围和风险集标签；图表未掩盖D−2反例。

在本轮固定LR配置和未校准验证概率下，近期湿度信息改善总体评分；**不能据此说湿度稳定改善新发生事件预测**。普通范围D−2新发生的2015/2016/2017年BS差分别为+0.000116、+0.006628、+0.001840；strict T中也均为正。D−1的改善不能抵消这个隔离对照反例。上述是观察到的验证表现，没有独立测试或置信区间，不据此宣称总体显著恶化，也不把D−1到D−2的变化单独归因于同化影响。两个空间范围高度重叠，不算两个独立的地区复制实验。

F4的总体验证BS优于本轮其他已完成简单基线，已作为各范围/lag的验证期基线名称保存，但F4同时使用夜间、区域和历史HI，不能用F4−F0差归因于湿度。F1−F0只回答纯温度输入上的近期湿度增量；本轮尚未执行F1P−F0P，不能声称已隔离出已知事件状态后的额外湿度价值。

本轮交付没有待修复的阻断性科学问题。后续仍须完成剩余预设模型/消融与选择冻结，再开展2018—2019校准和最终测试；当前产物不授权直接开放2020—2024。strict验证仍限T，尚未给出H区域迁移证据，亦未验证实时预警或工厂实际暴露。
