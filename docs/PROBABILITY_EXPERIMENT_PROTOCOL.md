## 2. 科学问题、样本与标签

主问题是：在固定时间和空间评价中，近期水汽信息能否改善次日湿热概率；新发生事件是否获益；增益是否跨年并在隔离对照中保持。模型复杂性本身不是研究贡献，负结果保留。

样本键为 `(grid_id, target_date_bjt)`，其中grid_id由稳定的经纬中心坐标生成，不能使用工厂编号。陆地规则沿用 `lsm>=0.5`；原配置区域为112—123°E、25—36°N。数据审计已核实45×45网格中的1,580个有效陆地格。五厂中同格的场所共享气象证据，掩膜拒绝的场所不补选邻格充当主结果。

目标为 `y(g,D)=1[max_hour HI(g,D)>=40.6°C]`，使用未四舍五入的摄氏HI比较。小时HI先由同一小时的T、Td及派生RH按现有方法计算，再取BJT日最大值，不能用日最高温度与日平均湿度重新组合标签。目标日必须有24个不同整点且所有所需小时值有限。缺值标签为缺失，绝不记为0。40.6°C沿用项目筛查阈值，不重新搜索阈值，也不称统一职业限值。

现有方法依据见 [ESG_FIVE_SITE_METHOD_AUDIT.md](ESG_FIVE_SITE_METHOD_AUDIT.md)。原处理文件的 `d2m` 是K保存的日最高露点，不是日平均露点；新的均值、最低值及夜间量必须从小时资料派生，命名带统计量与单位。HI日值虽然可能残留 `GRIB_units=K`，实际派生变量为摄氏度；不得再次减273.15。协议不修改现有HI公式或原NetCDF。

## 3. 时钟、完整窗口与ERA5限制

所有显示及切分按 `Asia/Shanghai`（固定UTC+8，无夏令时）；原始小时坐标保持UTC。目标窗口为左闭右开 `[D 00:00, D+1 00:00)` BJT，对应 `[D−1 16:00, D 16:00)` UTC，实际24个整点从D−1日16时到D日15时UTC。模拟起报时刻为窗口左端。

令输入滞后 `L∈{1,2}`，最后允许使用的完整BJT日期为 `A=D−L`。

| 定义 | 常规 L=1 | 隔离 L=2 |
|---|---|---|
| 输入最后整点 | D−1日23:00 BJT | D−2日23:00 BJT |
| 7个完整历史日 | D−7至D−1 | D−8至D−2 |
| 1、2、3阶日滞后 | D−1、D−2、D−3 | D−2、D−3、D−4 |
| 最近完整夜间 | D−2日20:00至D−1日08:00 | D−3日20:00至D−2日08:00 |
| 各自最早合格目标日 | 6月8日 | 6月9日 |

夜间端点明确为**左闭右开 `[20:00, 次日08:00)`**，共12个小时状态样本，最后整点是07:00；这不是能量积分。必须有12个不同整点且全部有效。夜间严格平移24小时，不得在隔离臂保留常规臂的最近夜间。用户计划中的降温幅度保留在NT，明确为 `T(20:00)−T(07:00)`，两个端点相隔11小时，正值为降温；12个窗口样本须全部有效，不能只检查两个端点。当前pilot实现均温、最低温及夜间湿度，降温量仍是待实现项，不能因子集试算已完成而省略。

公平主比较统一用**每年6月9日—8月31日，共84个目标日**，两臂共享同一 `(grid_id,D)` 索引。5月31日的8个UTC边界小时仅用于构成6月1日BJT，不构成一个可用的5月31日完整历史日。不能靠跨年shift或不足7日的rolling提前开始。6月8日常规臂可作单独覆盖附录，不进入主比较。

ECMWF说明ERA5大气4D-Var采用09—21 UTC及21—次日09 UTC的12小时窗口，窗口内较晚观测也可能约束较早分析；部分近地面变量另涉及陆面同化，不能据大气窗口反推出每个2米变量的完整观测谱系。ERA5T通常延迟约5天，日更新无固定时刻，最终版还会后续替换。因此本研究是**再分析条件下的历史回报**，不构成可部署实时预警。[ECMWF ERA5 data documentation，检索2026-11-05](https://confluence.ecmwf.int/spaces/CKB/pages/76414402/ERA5%2Bdata%2Bdocumentation)

按上述大气窗口推算，D−1日23时BJT等于D−1日15时UTC，其窗口可到D日05时BJT，越过模拟起报5小时；D−2臂对应窗口结束于D−1日05时BJT，比起报早19小时。这是选择整日隔离的依据与敏感性解释，**不是所有隐含未来影响已消除的证明**，更没有解决约5天的资料发布延迟。两臂均须保留这个适用限制。

## 5. 特征分组：分开回答两种湿度增益

固定非气象背景 `C`：经纬度、`sin/cos(2πdoy365/365)`、`sin/cos(4πdoy365/365)`。doy365去除闰日偏移，确保同一月日在各年编码相同。不用年份数值、网格ID目标编码、全时期均值或工厂信息。

对每个日变量x，`daily_history(x)`包含A、A−1、A−2三日值，以及A−2…A和A−6…A的均值、最小值、最大值。所有rolling右端为A，最少有效日数等于窗口长度。

| 组 | 固定内容 |
|---|---|
| T | `daily_history`作用于小时T计算的日mean/min/max（°C） |
| M | 同样作用于Td的日mean/min/max（°C）及小时RH的日mean/min/max（%）；日平均RH由逐小时RH平均而来 |
| NT | 最近完整夜间T均值、最低值，以及20→07时端点温差（°C，11小时间隔）；温差待实现 |
| NM | 同一夜间Td均值、RH均值；不增加隐含HI量 |
| RT | 固定邻域在A日的日平均T空间均值、空间标准差，以及3日/7日的该空间均值时间均值 |
| RM | 对日平均Td、日平均RH各作与RT相同的空间及时间统计 |
| H | `daily_history`作用于日最高HI（°C），加A日事件状态、最近3/7日事件比例、截至A的连续超阈日数（最多回看7日） |
| P | 仅A日事件状态，用于明确的持续性条件对照；该状态由温湿共同决定 |

预设特征臂：`F0=C+T`；`F1=C+T+M`；`F2=F1+NT+NM`；`F3=F2+RT+RM`；`F4=F3+H`。另设 `F0P=C+T+P`、`F1P=C+T+P+M`。主湿度增益为F1对F0；第二个问题为F1P对F0P，即“已知最近事件状态后，湿度的额外价值”。后者**不是无湿度基线**。

F0严禁历史HI、历史事件状态、事件连续日数、露点/RH、湿球/体感/露点差、区域湿度或事件气候概率作为输入。模型目标本身仍是温湿标签，使用训练标签拟合模型是监督学习必需步骤；禁令针对输入信息混入。F0/F1都不加入由标签拟合的网格气候态特征，以免混淆近期湿度与地点气候知识。季节概率作为单独强基线报告。

为区分“多了夜间时间分辨率”和“多了夜间湿度”，追加两个固定组移除对照：F2去掉NT、F2去掉NM；区域阶段对应F3去掉RT、F3去掉RM。F4对F3衡量综合热状态增量，不能据此单独归因于湿度机制。解释以这些配对差值、预设分组及典型过程为主；SHAP为辅助，不宣称地面关联识别出副高、平流或陆气反馈因果。

## 6. D−2臂的标签隔离和新发生评价

对任意L，持续性、转移状态、P/H、连续日数均截止A。D−2臂的条件转移明确拟合 `P[y(D)=1 | y(D−2), season_bin(D)]`，不是偷用D−1标签的一步转移；不得按D−1状态路由模型、校准器或告警阈值。原始D−1值即使因共同样本审计存在，也不能进入D−2特征矩阵。

评价中的事件状态用真实 `y(D−1), y(D)` 事后定义：新发生0→1、持续1→1、解除1→0、持续无事件0→0。“新发生”指前一日未超阈后的转为超阈，不是全年首次。

概率区分能力在完整风险集上报告：新发生风险集为 `y(D−1)=0`，同时含0→0和0→1；持续/解除风险集为 `y(D−1)=1`，同时含1→1和1→0。不能只在0→1阳性集合计算PR-AUC并声称识别了新发生。两类风险集分别报告样本数、发生率、BS、AP/PR-AUC、固定规则下混淆计数；四种转换单元另报数量、概率分布和命中/解除误警等。

对D−2臂上述分组是**事后诊断**，在起报时D−1状态不可用；不解释为一个能实时知道“明日将新发生”的分流系统。分组标签仅存放于评价表，模型接口拒绝它。冻结前可在验证年作同一定义的诊断；最终测试上的分组不再引发模型调整。

## 7. 四类强简单基线与有限复杂候选

1. **持续性**：`p=y(A)`，保留其0/1原始概率；不将0/1改称经验发生概率。D−2为两日状态持续性。其BS和告警混淆计数保留，log-loss如作为附录必须注明数值截断。
2. **训练期季节概率**：固定15日季节箱，`b=floor((D−当年6月1日).days/15)`，共7箱，最后一箱仅8月30—31日；共同样本下第一箱保留6月9—15日。普通时间实验使用 `(k(g,b)+20*p(b))/(n(g,b)+20)`，其中 `p(b)=(K(b)+1)/(N(b)+2)` 均来自训练共同样本；收缩强度20为固定默认。严格空间实验对留出格只用训练空间池的 `p(b)`，不估计该格专属气候态；同时把这个区域季节概率作为所有实验的透明附加基线。若整个季节箱无训练样本，不输出该箱预测并报告训练覆盖错误，再修复输入；不得借用未来资料。仅某格的箱未见时使用合法的训练池 `p(b)`。
3. **条件转移概率**：使用训练空间池中的 `(season_bin(D),y(A))` 计数，按 `(k(b,s)+20*p(b))/(n(b,s)+20)` 收缩。每个L独立拟合，不借用另一臂状态；稀疏状态自动回到训练季节箱概率。此版不按网格拟合转移，避免数十个样本估计极端概率。
4. **正则逻辑回归LR**：每个特征臂使用与LightGBM相同的可用信息；数值标准化仅由训练样本拟合；L2，`C∈{0.01,0.1,1,10}`，不加class_weight、不做过采样，截距不惩罚，最大迭代2000。未收敛候选标为失败并留档，不悄悄换求解或继续搜索；具体求解器及版本在执行前锁定。

LightGBM仅在基线与特征验收后启用：binary objective，learning_rate=0.05，num_leaves∈{7,15}，min_child_samples∈{100,500}，reg_lambda∈{1,10}，共**8个候选**；max_depth=-1、feature_fraction=1、bagging_fraction=1、class_weight=None，确定性设置、单线程、种子20261105。最大2000轮，在验证集binary_logloss连续100轮无改进即停止；候选按验证期逐年等权平均BS排序，再以较少叶子、较大min_child_samples、较大reg_lambda破同分。不得用测试或校准年早停。

超参数只在F4、L=1、普通时间实验中选择一次；选定LR的C、树的参数及轮数后，所有其他预设特征臂、L=2和空间实验复用这些结构设置，重新仅以各自合格训练样本拟合。普通实验中留出区域的标签若参与过选择，会污染严格空间实验，因此**空间实验另在严格训练空间的train/validation上重复同一有限搜索一次**，冻结其专用结构设置。各臂不独立追逐最佳参数，差值解释为相同学习配置下的信息增量；不保证每个消融臂都达到其最优性能。

简单基线比较包括四类基线在F4信息下的LR，以及F0 LR。基线名称在验证期按逐年等权原始BS选择并记录，测试年不换“最强基线”。所有原始候选与失败记录保留；同时报告各简单基线得分，避免只展示有利参照。训练模型不重拟合到2017或2019。

## 8. 概率校准和告警规则

主科学增量先报告**原始概率**的配对BS差，避免校准隐藏特征信息的来源；对应用可用性同时报告统一校准后的概率结果。特征、模型参数、简单基线名称先用验证期冻结；2018—2019只拟合预先固定的校准映射，不再在isotonic、温度缩放等方法间选择。

工程默认采用 `sigmoid(a*logit(clip(p,1e-6,1−1e-6))+b)`，a约束非负，最小化校准期log-loss，使用固定弱惩罚 `1e-6*(a−1)^2`，截距不惩罚。对每个需要报告校准概率的模型/特征臂/L分别拟合，两年等权；若校准样本单类或优化不收敛，返回恒等映射并记录失败，不尝试替代方法。原始持续性基线始终单列，不用校准后的两档转移概率替换它。最终测试同时保存raw与calibrated两列。

首个固定告警规则为 `p_calibrated>=0.5`。辅助规则为**校准期告警预算≤10%**：在阈值集合 `{0,0.01,…,1.00,1.000001}` 中选择使校准期格日告警比例≤0.10的最小阈值，两年等权，不根据事件标签挑阈值；最后一个值表示不告警。概率相同不拆散打破平局。阈值分别随冻结模型保存，测试年不重算分位数、不强制维持10%预算。持续性按原始概率同法报告。两个规则均为研究默认，不代表工厂安全行动标准；实际成本信息尚未获得。

校准期报告是拟合诊断，不能当作独立泛化结论。两年较短的校准代表性须在最终报告中说明。

## 9. 严格空间留出与区域特征

预先选定一个连续几何矩形：**核心区H为118—121°E、29—32°N（边界包含）**；扩展矩形E为117.5—121.5°E、28.5—32.5°N。缓冲带B为 `E\H`，宽度按经纬轴各0.5°，是角度矩形膨胀而非精确等距公里缓冲。仅按坐标与陆地掩膜定义；选择依据是域内的规则连续区域、远离外域边缘及固定几何尺度，不依据事件或预测效果。该矩形可能涵盖熟悉的案例区，故本实验是空间排除后的转移检验，不声称地理盲选。

所有年份的H与B均从训练、预处理拟合、验证选模和概率校准中排除。训练空间T为有效陆地格中不在E的部分；测试只评价H的2020—2024年。H的2000—2019标签不能拟合其气候态、特征缩放、网格编码、条件概率或校准器。B完全不用于模型拟合或邻域来源，不作为“额外训练格”。空间模型的校准只能用T的2018—2019；空间结果不能复用普通全域模型/缩放/校准器。

本实验允许在H的起报时使用按本协议可用的**近期本格气象及历史HI/事件状态作为预测输入**，因为问题是“模型未在该地拟合、但有该地近期气象时能否迁移”。这与使用H历史标签拟合专属参数不同；不把该实验称为完全无本地观测的冷启动。纯温度臂仍不能用H的历史HI或事件状态。

邻域固定为中心格周围 `|Δlon|<=0.5°且|Δlat|<=0.5°` 的陆地格，**不含中心格**，空间均值与总体标准差（ddof=0）等权计算。普通时间实验在有效全域内裁剪；严格实验中T查询只用T来源，H查询只用H来源；H、B、T之间不跨区拼接邻域，也不先计算全域区域统计再切分。每个查询邻域至少3个固定来源格，来源名单由坐标与掩膜冻结；任一所需来源值缺失则该区域量缺失，不随当日数据变化挑格。

[静态几何审计](../data/probability_phase1/geometry/geometry_audit.json)已核实H=165、B=113、T=1,302个陆地格，H全部位于同一个四邻接分量。普通时间实验1,580格全部满足至少3个邻域来源；严格实验有3个训练查询格不满足，故主训练/验证/校准查询空间为**1,299格**，H的165格全部合格。区域来源仍采用原先固定的1,302个T格，不递归删除来源格；这3格不用于监督拟合目标，但可作为合规T气象邻域来源。每格来源及其哈希已保存，几何门槛通过。

几何门槛原设为H至少50格、T至少500格、H最大四邻接连通分量至少90%、存在合格邻域，现无需修订。一次连续留出不证明对所有未知区域均能迁移，空间实验的区间仅反映该留出区的时间不确定性。

## 10. 共同样本、缺测与拟合范围

先按日历产生每年84日的候选索引，再按掩膜和严格空间几何产生对应实验索引。主比较使用所有预设特征、两种L的**完整输入并集所允许的共同样本**，具体要求：本格D目标日和D−8…D−1八个历史日所需小时T/Td完整；最近两种夜间完整；预设区域来源和相应历史日完整。D−1标签的有限性已由L=1完整HI输入自然保证，仅在评价表用于事后转换分组；不为单独D−2臂额外要求一个预测时不可用的状态。每个剔除原因单独计数，报告交集损失。D−2只共享合格索引，不共享D−1输入。

这是一套回报研究的共同观测完整性条件，不是宣称实时资料可得。既不按目标是否为事件过滤，也不因某模型运行失败给该模型另建较容易的测试集。所有比较在完全相同的键上join并验证唯一性。普通时间实验与空间实验各有自己的共同索引；两者的区域不同，不直接把平均分差归因于迁移损失。

主分析不插补缺失气象、标签或不完整夜间，不由LightGBM隐式缺测路径绕过公平样本规则。不足7日的窗口不缩短、不以零补齐。缩放等参数只在各实验合格train上拟合；不允许全数据fit后再切分。

结构样本清单已核实普通主实验上限为3,318,000格日：train 1,990,800、validation 398,160、calibration 265,440、final_test 663,600，共2,100个目标日期。它们是几何与日历**结构上限**，并未完成所有新特征的有效性判定；空间和邻域筛选会改变实际计数。

## 11. 指标、配对比较及不确定性

主评分单位是同等权重的有效陆地格日，先计算每年的BS，再对年份等权平均；面积加权cos(latitude)结果为明确标记的敏感性分析。`ΔBS=BS(candidate)−BS(reference)`，负值表示改善；`BSS=1−BS(candidate)/BS(reference)`，正值表示改善，参考BS为0时BSS记NA并保留绝对差。每个对比注明基线名称、特征臂、L、空间范围、raw/calibrated、共同样本数和发生率。

概率排序同时报告以下两个不同量，禁止混用名称：

- **AP（average precision）**：按recall增量对precision作阶梯加权的平均精确率，作为主要PR摘要；给出事件发生率以解释难度。
- **PR-AUC-trapezoid**：按recall递增对经验precision-recall曲线作梯形积分，作为辅助指标；实现固定端点及同分概率处理，记录库版本。它与AP数值通常不同。风险集无阳性或无阴性时相关区分指标记NA并报告计数。

具体曲线规则：概率降序排列，每个相同概率组一次性纳入，按累计TP/FP产生precision、recall；起点设为 `(recall=0,precision=1)`，终点是全部样本纳入时的 `(1,发生率)`。AP为各段recall增量乘该段末端precision，梯形面积对相邻点线性连接求积；不得用任意同分排序制造区分能力。常数预测的AP为发生率，而该端点约定下梯形面积为 `(1+发生率)/2`，故梯形值较高本身不表示有技巧。

可靠性图使用固定边界 `[0,0.1,…,1]`，各箱左闭右开，最后一箱含1，每箱报告样本数、阳性数、平均预测与实测率，不对空箱插值；补充原始与校准后的整体BS、log-loss（注明1e-6截断）及校准截距/斜率诊断。诊断拟合不反馈预测器。

两种冻结告警规则均报告TP、FP、FN、TN、召回率、precision、FAR=FP/(TP+FP)、FPR=FP/(FP+TN)、漏报率、每格每夏季告警日数分布及区域总格日告警比例。分母为0记NA，不给0或完美值。不得把格日告警数称为独立天气过程数。

固定分组为逐年、上述新发生/持续风险集，以及四个几何子区：以117.5°E和30.5°N二分全域，坐标等于分界归东/北。空间实验报告其核心区及可用子区。典型过程采用冻结模型后按明确错误类别选择的说明性案例，不能把挑中的过程替代整体评价。

不确定性使用**配对层级块bootstrap**：种子20261105、2000次；先从可用测试年份中有放回抽取5个完整年份，再在每个抽中年份内抽取长度14日、非循环、连续的移动天气块，拼到84日并截断最后块；每个抽中日期携带全部空间格及全部模型预测、标签和原样缺测掩膜。不得逐格日独立重采样。块起点均匀从当年允许的连续日期中抽取，绝不把8月31接到6月9或另一年。候选和基线在同一重复样本上算差值；每次重新计算聚合分母和BSS。

报告差值的2.5%/97.5%分位区间，并固定附加7日和21日块长敏感性、5个年度差值以及逐次删去一个测试年的均值。只有5个年份，bootstrap区间依赖有限年份可交换性和块长度，2000次重采样不会创造新年份；不得用数百万格日制造过窄独立样本区间、精确p值或“99.9%确定”结论。默认BS/AP和差值最多4位小数、发生率/告警比例1位百分数，同时保留原始计算文件。不同块长结论不一致时报告不稳定。

主确认对比为F1−F0的湿度增量；F1P−F0P是条件增量；其余消融、子区和过程作为预设次要诊断。多个相关比较不做逐项“显著发现”筛选。进入应用扩展的证据至少包括：复杂模型优于验证期冻结的最强简单基线，5个测试年中至少3年改善，在新发生风险集与D−2隔离中同向且有支持，校准没有明显失真。区间跨0时称证据不足；次要结果不能推翻失败的主对比。若树无稳定优势，保留简单模型。

## 12. 冻结门槛、记录与ESG出口

训练启动前必须形成可复核清单：

1. 原始数据文件清单与版本指纹；小时UTC及BJT转换检查；T/Td单位、日聚合含义、HI标签一致性；缺小时/重复小时/NaN处理通过。
2. 每年候选/有效/剔除格日表；两臂首日及跨年断开证据；共同索引哈希；证明D−2输入最大日期≤D−2、夜间终点≤D−2日08时。
3. H/B/T坐标成员及哈希、连通与邻域来源审计；训练/验证/校准无禁区标签、区域来源无跨区证据。
4. 协议与JSON一致性、特征允许列表、有限实验登记表、种子、依赖版本、源码版本；训练/验证/校准/测试文件访问边界；已有2017/2022接触声明。

冻结后每次实验记录数据清单哈希、代码提交或工作树差异哈希、协议版本、完整特征名及窗口、空间成员、年份范围、种子、超参数、早停轮数、失败原因、验证指标、校准参数和告警阈值。最终预测表至少含grid_id、经纬度、空间角色、目标BJT日期、起报UTC/BJT、目标窗口UTC/BJT、L、输入最大有效时刻、模型/协议版本、p_raw、p_calibrated、告警阈值、y_D、事后y_D−1、样本资格。评价标签在独立表join，不进入推理接口。

原始101份文件（75月文件、25份5月31日边界、1份掩膜，总366,301,416字节）及4份BJT NetCDF已匹配既有验收指纹；新副本配置与原配置的差别仅为换行编码，规范化内容一致。2000年6月全2,025格独立小时重聚合与现有Tmax、最高Td、meanRH、HI最大差均为0；同一pilot中最高Td与平均Td最大差8.5153°C，证明二者不能混用。这是有限月份的聚合核对，不冒充25年小时内容全重算。

2000年训练期JJA另已提取全域92天的7项日/夜变量，3个训练格的42行滞后pilot全部有限，详见[字段字典](PROBABILITY_DATA_DICTIONARY.md)及[pilot样本](../data/probability_phase1/feature-pilot-2000/lagged_feature_pilot.csv)。它验证了平均露点与12点完整夜间的工程口径，没有实现本协议全部M组极值、区域特征及全期共同mask。季节与转移基线工具已做合成验证，未以真实资料拟合。现阶段尚未生成新的最终测试表现或事件率统计。

剩余实质阻塞为完整注册特征提取、全期特征共同索引与执行环境：当前科学Python可读取资料，但尚未安装scikit-learn/LightGBM，故相应模型尚不能运行。如既有文件不覆盖某特征，先记录缺口，不先下载、不换指标、不静默缩小范围。冻结时补入最终审计链接、结果与协议哈希；无需为了文书形式重复已经通过的数据检查。

场所出口仅在科研评价完成后生成湿热证据卡、空间代表性说明、潜在影响路径、信息缺口和监测准备建议。HI不等于厂内WBGT、劳动暴露、停工准则、财务损失或完整披露合规。工厂的掩膜拒绝、同格重复与缺失证据继续显示，不把模型概率补成已经验证的场所风险。
