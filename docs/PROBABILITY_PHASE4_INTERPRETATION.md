# 第四阶段结论与适用范围

冻结后的2020—2024正式评价完成，H空间留出也已实际评价。**本轮不支持用LightGBM_F4替换验证期已冻结的LR_F4，也不支持宣称D−2湿度信息稳定改善新发生事件。** 同时，D−1的湿度增量有明确的本次回报证据；不能把负面结果概括成“湿度无用”。数值均来自[完整结果](PROBABILITY_PHASE4_RESULTS.md)及预定配对表，没有重新挑选模型或阈值。

下表是预定主算法LightGBM的F1−F0原始BS差，负值表示加入湿度后改善。区间为14日配对层级bootstrap的95%区间；H仅代表这一留出区，不能推广到所有未知地区。

总体样本的改善不能代替新发生证据。D−2全域新发生均值仍变差；H均值虽有改善，但区间跨零，不能宣布稳定收益。LR的D−2新发生也有相同的范围差异：全域ΔBS约+0.0002（2/5年改善），H约−0.0013（4/5），两区间都跨零。验证期已有的D−2反例保留在第三阶段报告，不能用本轮H的正面均值覆盖。F1P−F0P是状态条件下的另一问题，也没有为D−2新发生提供排除零的区间支持。

## 算法复杂度与校准

固定F4模型在全域的树−LR原始BS差为D−1 **+0.0029**、D−2 **+0.0080**，两个lag的全体样本均0/5年改善。H的全体均值差分别为−0.0002和−0.0016，但都只有2/5年改善、区间跨零；H新发生的均值反而变差。两个scope均未通过开封前的跨lag/风险组稳定优势门。因此继续保留原先冻结的LR_F4作为简单研究候选，并不把它视为已经获准业务部署的模型。

100个生产概率映射都成功拟合，4个持续性基线保持原始0/1；这只说明固定算法完成了拟合。全体样本BS改善不能说明每个风险集都改善：全域D−2新发生中，LR_F4校准后BS从0.1013变为0.1073（差+0.0059，区间[+0.0044,+0.0105]）；LightGBM_F4从0.1030变为0.1108（差+0.0078，区间[+0.0042,+0.0141]）。这属于保留的校准退化反例，未重新拟合或选择其他映射。

可靠性图的尾部必须结合计数。例如H的2023/D−2 LightGBM_F4校准概率≥0.9的箱只有2个格日、0次事件，不能把该箱的0发生率当作稳定估计。固定十箱的全部计数与逐年曲线已保存。

## 已知失败与证据限度

生产映射的数值回退为0；另外的**事后校准截距/斜率诊断**出现4条优化失败，按冻结规则记NA，不改变概率：校准期为temporal/D−2/transition/2018/calibrated一条；正式期为temporal/D−2/persistence/2022的raw及calibrated两条（同一原始概率的重复诊断），以及temporal/D−2/transition/2023/calibrated一条。没有换优化器、重选规则或把NA当作完美校准。

21,600条预定配对区间均具有完整2,000次有效重复；7/14/21日敏感性和五个逐次删年结果均保留。这些区间仍只有五个年份的信息，条件于已有模型和校准参数，不包含训练、选择及校准参数不确定性。本轮不做精确p值、多对比择优发现或气象因果声明。

## 后续工作边界

本阶段已经完成冻结、校准、正式评价及H留出。下一项实质工作是把这些证据与五个制造业场所的既有地理匹配、数据可用性和适应信息衔接；应以LR_F4及原始强基线为参考，保留D−2新发生和校准退化，不因本次测试结果追加参数搜索。若提出新模型，只能另立开发与验证方案，2020—2024此后应视为已接触测试资料。

ERA5发布延迟和同化窗口限制仍存在；结果是历史回报，不是实时预警。场所层面的气候危害筛查不能推导厂内WBGT、职业安全行动阈值或财务损失。2017/2022案例历史接触已经披露，本轮不是全新盲测。
