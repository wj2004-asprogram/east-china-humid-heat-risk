## 数据与结果复用

1. 核验实际使用的原目录、历史/空间清单与文件哈希。复用既有2000—2024完整JJA历史统计、原典型年/极端年选择及连续过程，不重跑25年小时数据。
2. 从第四阶段已生成的enriched NPZ提取固定LR_F4、LightGBM_F4、持续性、季节概率、池化季节概率和条件转移，两个lag、五年全部保留。LR_F4来自原验证冻结，不能因某个场所成绩改变候选。
3. 按原格点索引连接日期字典，保留起报/目标窗口、输入截止、raw/cal概率、两种原告警阈值、标签及D−1评价状态。核对所有模型/lag的共同键和标签，并与原未舍入日HI及D−1阈值标签逐日对照。
4. 只作网格子集的描述性评价：逐年、五年等权、all/onset/持续解除风险集、BS/AP/截断log-loss、固定十箱可靠性、原两种告警规则。D−2的新发生分组仍是事后诊断。无重新拟合、阈值变化、当地模型选择或新增置信区间/显著性检验；区域CI不能移植为单厂CI。
5. 同格厂通过关联表复用结果，预测明细以grid/scope/model/lag/date去重保存。两套scope的结果并列标明含义，不在场所层挑选更好的scope。

## 应用证据卡与建议

每厂卡含：身份/地址快照及来源、主格及掩膜、空间代表性、完整JJA历史、84日窗口的模型回报、区域方法证据与不确定性、潜在影响路径、明确数据空缺、下一步验证任务。四层证据分开标为“已有公开/气候证据”“合理但未验证路径”“缺失现场数据”“待验证建议”。

影响路径仅讨论湿热背景可能关联的人员热负荷、冷却需求、潜在生产/质量影响，均须现场条件才能验证。未知员工数、岗位、班次、工作强度、风/辐射、防护服、冷却设施、能耗、停产和损失保持空值；不把行业名称当作现场工艺证据。

监测优先级是补证工作队列：先解除定位/代表性障碍；再核定观测覆盖、厂内外差异与时间对齐；最后以真实运行记录检验影响路径。不同队列可以并行，不给企业热风险或财务风险打分。杭州三厂可共享格点背景，但现场样本不能互相替代；采埃孚须先核清同址生产单元；特斯拉的缺值不是低危害。

HI≥40.6°C继续只是本项目操作阈值，不转换为停工、职业合规或损失标准。未验证建议不触发实际排班、现场处置或对外联系。下一步现场测量、独立观测及带起报时间的真实预报资料须另行取得。
