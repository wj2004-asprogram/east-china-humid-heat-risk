# 五场所交付：模型使用补充

本说明补充[冻结模型说明](PROBABILITY_MODEL_CARD.md)，不修改第四阶段模型、数据切分、校准或告警规则。

本轮发布的是五场所背景危害证据和已经完成的概率历史回报。它可用于追踪气候资料、比较研究方法、规划需补充的信息；尚不支持实时预警、工厂热暴露估计、职业合规或财务损失判断。阶段五没有新模型文件或业务预测接口。

## 输入、版本与回报含义

源版本为第四阶段完成提交 `4bb4028977ee3ad75d2035e60887491f53096a49`，三个seal保存在 `data/probability_phase4/`。本阶段协议为 `ehhr_probability_phase5_sites_v1`；身份和边界证据快照为2026-10-29，不含当前在营或现场确认。

固定候选为LR_F4、LightGBM_F4、持续性、15日季节概率、池化季节概率、条件转移。F4有117列注册特征，涵盖季节/位置、温度、湿度、已结束夜间、限定区域、滞后HI和状态。模型训练2000—2014，选择2015—2017，校准2018—2019，正式评价2020—2024。没有把后来年份重新并入训练。

LR_F4由原验证冻结，C=0.1；LightGBM沿用temporal的15叶/100最小叶/667轮和strict的7叶/500最小叶/928轮，两者L2均为10。第四阶段没有支持稳定的树替换收益。所有场所都保留两种算法及四个简单基线，不能根据场所测试成绩挑选候选。

回报目标是北京时间目标日的日最大HI≥40.6°C。D−1、D−2分别只允许最晚D−1、D−2的23:00有效时间输入，起报标记为目标日00:00。这是有效时间约束，不是实际发布时间证明。D−2的D−1评价标签不能进入预测或按该状态分配校准器。

## 输出及空间适用性

预测明细保留目标日、起报时间、输入截止（BJT和UTC）、格点、空间角色、模型、lag、原始/校准概率、标签、D−1评价标签及原告警阈值/标记。标签是事后评估附表，不是业务可用特征。表以格点去重，场所经映射关联。

杭州三厂共享30.25,120.50格，位于H，因此两种scope都可取：temporal跨年回报使用本区域早期训练数据；strict模型只在T拟合，H推理仍可用允许时刻的近期当地气象。两种scope并列，不能相减解释为纯迁移损失。采埃孚31.00,121.50为buffer，只提供temporal。特斯拉主格30.75,121.75被掩膜拒绝，历史和概率为空，不替换为附近有效格。

完整JJA历史为92日/夏；统一模型窗口为6月9日至8月31日84日/夏。不能把两个窗口的事件天数直接当成同口径变化。2000—2024的格点历史不意味着企业在整个时期运营。

## 概率和告警的解释

原始概率是原定科学主比较；校准映射和阈值来自2018—2019，未经场所再拟合。全体BS改善不保证新发生组改善；两条有效主格temporal D−2的LR新发生BS校准后均略变差，报告保留该现象。AP、BS和可靠性计数应一起读，少量高概率样本不能证明当地概率稳定可靠。

原主告警为校准概率≥0.5；预算规则在校准期按固定阈值网格控制两年等权告警比例≤10%。未来、测试或某个当地格的告警比例不保证≤10%。预算阈值可能为1.000001哨兵，表示不发出研究告警，不是有效概率超过1。这些规则没有使用工厂人员、行动能力或误报/漏报成本，不能触发停工、排班或投资决定。

年度和五年等权指标仅作描述；只包含五个测试年。新发生风险集含00与01，杭州157个格日中40个事件、采埃孚210个格日中44个事件。未生成单厂置信区间，也未把区域bootstrap区间套给单格。四个有效场所只有两个气候序列，不能据此估计工厂间差异或验证企业风险模型。
