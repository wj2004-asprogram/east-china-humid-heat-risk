# 长三角制造业场所：公开数据试点

## 决策与本轮边界

2026-10-29 用户选定：先用公开可查询数据搭建一部分，再与 ESG 行业人员对接；首批为长三角制造业工厂。目标是帮助企业比较场所的历史环境热暴露，并保留后续核实与行动记录所需的证据。第一版不生成企业 ESG 总分，不推断损失、职业健康合规或员工实际暴露。

阶段安排：

1. 获取候选地点，先核验 5 个生产地址，再整理约 30–50 个可追溯样本。
2. 接入已有 2000–2024 年夏季 ERA5 结果，输出场所汇总和逐年明细。
3. 简易界面已完成：地点列表、环境指标比较、逐年图表、证据来源、待补信息、导出；默认仅显示已核验场所。入口为 `apps/factory-pilot/dist/index.html`。
4. 用可操作的原型访谈 3–5 名 ESG / 企业安全或可持续发展人员，确认使用频率、输入字段、决策价值，再决定是否扩展实时预警或机器学习。

这是 ESG 应用探索分支，不代表原路线图中的机器学习阶段已获导师确认。

## 公开来源与用途

| 来源 | 可用内容 | 本试点用法 | 主要限制 |
|---|---|---|---|
| 已处理的 ERA5 单层再分析 | 本地 2000–2024 JJA、北京时间日最高 HI、陆地掩膜 | 复用已验收结果 | 0.25° 网格、历史环境条件，不能代表车间或工人个人暴露 |
| [OpenStreetMap works 标签](https://wiki.openstreetmap.org/wiki/Tag:man_made=works) / [Overpass](https://wiki.openstreetmap.org/wiki/Overpass_API) | 名称、坐标、部分生产/行业标签 | 获取候选工厂地点 | 标签可能覆盖厂区或其生产单元；覆盖不全、身份及在营状态未经核实；不是官方工厂名录 |
| [全国排污许可证管理信息平台公开端](https://permit.mee.gov.cn/) | 单位名称、行业、生产经营场所地址、公开许可信息 | 核对前 5 个样本及后续企业实体 | 未确认可用的批量开放 API；公开可查询不等于允许无限抓取；不把排口坐标当成厂区或工位坐标 |
| 企业官网和公开年报 | 部分生产基地地址、业务和生产活动 | 补充工厂与企业的对应关系 | 不把总部地址当作生产地址；不把集团员工总数分配到工厂 |

OSM 数据遵循 [ODbL](https://www.openstreetmap.org/copyright)，保留 © OpenStreetMap contributors 及许可链接。分发提取或改编的地点数据库时，按该许可保留相应要求；代码许可与第三方数据许可分别记录。首次候选查询范围为纬度 29.5–32.5°N、经度 118–122°E，这是长三角部分范围的便利样本，不代表整个长三角或整个制造业。

## 获取进展：5 个已核验场所，30 个待核验候选

本轮本机访问 `overpass-api.de`、旧备用 `overpass.kumi.systems` 及当前备用 `overpass.private.coffee` 均发生读取超时，未取得有效响应。首次受沙箱网络限制的调用已按流程升权重试；升权后的问题是网络读取超时，不是 403 或 API 令牌权限不足。没有修改网络、代理或令牌。

后续阶段已找到可用的 OpenStreetMap 主站 API。先取得特斯拉上海、长安福特杭州、费列罗杭州、格力杭州、采埃孚上海元江路 5 个厂区的原始闭合边界，再用工信部公示、政府抽检、企业官网和公开生产证书交叉核对生产实体与地址。完成首批核验并保存阶段快照后，才获取闵行、太仓两个小范围地图响应，扩充为 35 个地点。完整记录见 [核验报告](ESG_FACTORY_VERIFICATION.md)。

“已核验”指公开资料桌面核验，不等于现场审核或当日在营确认。其余 30 个仅为 OSM 候选，生产地址、实体、行业与员工信息不推断。原始证据保存在本机输出目录；仓库保存事实字段、来源 URL、获取时间、哈希与使用许可说明。

此前准备的只读查询（本阶段未执行，保留为备选路线）：

```overpass
[out:json][timeout:25];
nwr["man_made"="works"]["name"](29.5,118.0,32.5,122.0);
out center tags;
```

必须保存原始响应、查询、接口 URL、获取时间、OSM 数据库时间和 SHA-256。节点直接使用公开节点坐标；way/relation 的 `center` 是包围盒中心，不是实测工厂中心。记录 `coordinate_method`，保留 OSM 对象 ID 和 URL。核查同一厂区的重复节点/多边形，不按名称简单合并同名异地工厂。停止、废弃、非制造业设施应排除或单独标记，并保存理由。不要为凑足样本编造地点。

## 已实现的最小数据工具

`tools/esg_site_screen.py` 读取场所 CSV 与已有气候 NetCDF，输出：

- `site_summary.csv`：来源字段、匹配网格、距离、数据状态、完整夏季数、每个完整夏季平均达到阈值的天数、最长连续达到阈值天数。
- `site_annual.csv`：逐场所逐年有效天数、完整性、达到阈值天数及最长连续天数。
- `screening_manifest.json`：输入/输出哈希、时区、日期范围、阈值及统计口径。

输入模板：`data/site_inputs/factory_sites_template.csv`（只有表头）。真实输入为 `data/site_inputs/factory_sites.csv`；核验决策为 `factory_review.json`，可追溯目录为 `factory_sites.json`，对应边界为 `factory_boundaries.geojson`。必填 `site_id,name,latitude,longitude,source_url,coordinate_method`。本阶段坐标来自 OSM WGS84，未使用 GCJ-02 / BD-09。`site_verification` 区分 `candidate_unverified` 与 `verified_public_sources`，并保留核验依据。员工人数、班次、防护措施无证据，全部留空。

示例命令（路径替换为实际输入，不执行下载）：

```powershell
python -m tools.esg_site_screen `
  --sites <factory_sites.csv> `
  --heat-index <humid_heat_jja_2000_2024_bjt.nc> `
  --risk <heat_risk_categories_jja_2000_2024_bjt.nc> `
  --output <new_output_directory>
```

统计规则：

- 复用已有 `daily_max_heat_index_c`，不重算或修改科学公式。默认阈值 HI ≥ 40.6°C，继承 `src.risk.CATEGORY_THRESHOLDS_C[3]`；可显式选择其他阈值，输出记录实际值。
- 只接受明确标注北京时间的 JJA 日数据。每年预期 92 天；缺日期、NaN、无穷值均使该夏季不完整，不完整年份不进入均值或最长连续天数，完整夏季数必须一同展示。
- 最近经纬度网格，等距时采用文件坐标顺序。拒绝越界，报告地理距离；最近网格非陆地时返回 `non_land_grid`，不擅自改选陆地。
- 连续天数在每个夏季重新计数，绝不跨越冬季连接。缺失整个年份也要保留不完整记录。
- 同一网格的地点共享同一套环境指标，不制造工厂级空间精度。候选厂址与网格中心的距离不等于位置误差或置信区间。
- 历史值描述“当前候选位置在历史时期的气候条件”，不证明工厂当时存在或工人当时暴露于这些条件。
- 输出不得覆盖输入，前后检查输入哈希。代码不读取 CDS 状态库、发起 CDS 请求或下载新气候数据。

## 验收及下一步

新增针对阈值等号、跨夏季连续天数、缺天/NaN/无穷值、整年缺失、越界坐标、共享网格、海洋网格及网格不匹配的 12 项测试均通过。真实气候接入验证使用仓库已有的南京、上海、杭州、淮安城市坐标和已验收城市时序作为对照：4 城市 × 25 夏季共 100 项逐年核对，达到阈值天数与最长连续天数全部相同，每夏季 92 天完整；读取的气候文件和输入 CSV 前后 SHA-256 一致。城市对照不是工厂样本。

本机验证证据：`<LOCAL_EVIDENCE_ROOT>\esg-public-pilot-20261029\city_control_verification.json`，CLI 日志 `city_control_cli.log`，输入输出哈希和结果在 `city_control_screening/`。这些环境特定证据不作为工厂结果提交到仓库。

本阶段首批 5 个生产地址交叉核验已完成。35 个地点中 34 个气候可用，1 个为最近网格非陆地；共 4 个可用网格。850 条逐年记录重新计算一致，18 份来源快照哈希通过，20 项 Python 测试和 14 项浏览器检查通过。核验结果为 Codex 自审，不是独立审阅。详见 `docs/validation/ESG_FACTORY_PILOT_20261029.json`。下一步是核验剩余候选、增加地域和行业覆盖，并用当前原型准备行业访谈；尚未联系外部人员，也未开展现场验证。
